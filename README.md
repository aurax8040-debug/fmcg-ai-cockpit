# 快消智析 · AI经营驾驶舱

这是当前主作品的唯一源码目录。旧“每日经营Demo”只作历史原型保留，不与此仓库混合。

## 运行与配置
需要Node.js 22。使用现有双击打开AI经营驾驶舱.command启动；Dify与Docker需按本机配置准备。密钥只放本机.env.demo，不上传。
静态预览可运行 `node scripts/static-preview.mjs`；预览端口与路由以脚本为准。

测试：`node --test tests/*.test.mjs`。测试使用模拟服务，不消耗真实模型额度。外部Dify真实联调需单独验证，不属于纯回归测试。

## 版本管理
- main：验收后的主线；新修改使用codex/主题分支。
- baseline-2026-10-25：接入版本管理时的源码存档，不代表全功能验收。
- 每次修改：确认目录/分支 → 看差异 → 测试 → 提交 → 推送。
- 不直接reset --hard或强制推送；撤销已共享改动优先revert。
- 后续不再建立“最终版2/备份3”源码目录。旧快照保留但不继续开发。

教程见docs/版本管理从零开始.md。运行数据、浏览器记录、密钥及Dify服务本身不包含在Git存档内。dify目录中的DSL是代码中的导出版本，不保证等于当前Dify线上配置；修改工作流后需导出、去密钥、评审后再提交。
